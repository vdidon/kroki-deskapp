# D2

**API ID**: `d2` | **Output**: SVG | **Best for**: Architecture, ER diagrams, clean modern look

## Syntax

### Shapes
```d2
node                        # rectangle by default
node: My Label              # custom label
node: { shape: circle }     # inline shape
node.shape: diamond         # separate property
```

Shapes disponibles : `rectangle` `square` `circle` `oval` `diamond` `hexagon` `cloud` `cylinder` `queue` `package` `page` `document` `parallelogram` `step` `callout` `stored_data` `person` `c4-person` `text` `code` `class` `sql_table`

### Connections
```d2
A -> B              # directional arrow
A <- B              # reverse arrow
A <-> B             # bidirectional
A -- B              # line without arrow
A -> B -> C         # chaining
A -> B: label       # with label
```

Arrowheads : `triangle` `arrow` `diamond` `circle` `box` `cf-one` `cf-many` (crow's foot)
```d2
A -> B: { target-arrowhead: { shape: diamond; style.filled: true } }
```

### Containers & Nesting
```d2
server: {
  handler: Request Handler
  db: Database
}
client -> server.handler: HTTPS   # dot notation for nested access
server.handler -> server.db
_ -> server                       # _ = reference to the parent
```

### Styles
```d2
node.style.fill: "#f0f0f0"
node.style.stroke: "#333"
node.style.stroke-width: 2
node.style.stroke-dash: 3
node.style.border-radius: 8
node.style.opacity: 0.7
node.style.shadow: true
node.style.3d: true               # rectangle/square only
node.style.multiple: true         # visual stacking
node.style.double-border: true    # rectangle/oval only
node.style.font-size: 14
node.style.font-color: "#ff0000"
node.style.bold: true
node.style.italic: true
node.style.underline: true
node.style.animated: true         # animated connections
node.style.fill-pattern: dots     # dots | lines | grain
```

### Classes (style reuse)
```d2
classes: {
  server: { style.fill: "#dae8fc"; style.stroke: "#6c8ebf" }
  warn:   { style.fill: "#fff2cc"; style.stroke: "#d6b656" }
}
web.class: server
cache.class: [server, warn]       # multiple classes, applied left→right
```

### SQL Tables
```d2
users: {
  shape: sql_table
  id: int { constraint: primary_key }
  email: varchar(255) { constraint: unique }
  role_id: int { constraint: foreign_key }
}
users.role_id -> roles.id
```

### Markdown & LaTeX text
```d2
explanation: |md
  ## Title
  - item 1
  - item 2
  **bold**, _italic_
|
formula: |latex
  \sum_{i=0}^{n} x_i
|
```

### Global direction
```d2
direction: right    # up | down | left | right (default: down)
```

## Options (Kroki parameters)

- `theme`: `0`=Default, `1`=Neutral Grey, `3`=Flagship Terrastruct, `4`=Cool Classics, `5`=Mixed Berry Blue, `6`=Grape Soda, `7`=Aubergine, `8`=Colorblind Clear, `100`=Vanilla Nitro Cola, `101`=Orange Creamsicle, `102`=Shirley Temple, `103`=Earth Tones, `104`=Everglade Green, `105`=Buttered Toast, `200`=Terminal, `201`=Terminal Grayscale, `300`=Origami
- `layout`: `dagre` (default, fast) | `elk` (fewer crossings, orthogonal) | `tala` (software architecture, most advanced)
- `sketch`: `true` | `false` — hand-drawn rendering
- `pad`: pixels of margin around the diagram

Layout specifics:
- **TALA only**: per-container `direction`, `near`, `top`/`left` for fixed positions
- **ELK + TALA**: `width`/`height` on containers
- **Dagre**: no direct ancestor→descendant connection

## Gotchas

- Connections reference the shape's **key**, not its label
- Keys are **case-insensitive** (`db` = `DB`)
- Shapes 1:1 (circle, square) : if `width` ≠ `height`, the larger value is used for both
- `sql_table`/`class` : `stroke` = body background, `fill` = header color
- `direction` global only with dagre/elk; TALA allows it per container
- Terminal theme: forces uppercase, monospace font, no border-radius

## Examples

```d2
# Architecture microservices
direction: right

client: Browser { shape: person }
gw: API Gateway { style.fill: "#dae8fc" }
auth: Auth Service { shape: hexagon }
db: PostgreSQL { shape: cylinder }

client -> gw: HTTPS
gw -> auth: verify token
gw -> db: query
auth -> db: user lookup
```

```d2
# ER diagram
users: {
  shape: sql_table
  id: int { constraint: primary_key }
  name: varchar(100)
  org_id: int { constraint: foreign_key }
}
orgs: {
  shape: sql_table
  id: int { constraint: primary_key }
  name: varchar(200)
}
users.org_id -> orgs.id
```

```d2
# Container with styles and classes
classes: {
  svc: { style.fill: "#f9f"; style.border-radius: 8 }
}
backend: Backend {
  api: REST API
  worker: Job Worker
  cache: Redis { shape: cylinder }
  api.class: svc
  worker.class: svc
}
backend.api -> backend.cache
backend.worker -> backend.cache
```
